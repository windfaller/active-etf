# 首批內容、登入與快取

本次以正式站對應的 `77825d3db2f67c9e0f056540fbb311b049d76813` 為基準，於隔離分支修正。原本主目錄的既有未提交修改未變更；本次未公開部署。

## 已確認的等待與修正

- 登入入口的 `v-else` 原本接在「登入說明視窗是否開啟」上，造成訪客同時看到登入與會員按鈕。改為訪客／會員兩個互斥分支，保留中央登入交接與會員 MCP／Skill 選單，支援 Escape 關閉。
- 直接進入任一路由立即使用正確的 route；沿用現有分頁 chunk 與目前頁面的 module preload。換頁立即捲回頂端，不等待 API 才回應導航。
- 一般 session 驗證與資料讀取並行，伺服器仍逐次驗證 cookie 和會員投影。只有舊版一次性 token 換 session 的回呼先完成換證，再開始資料讀取，避免先取到訪客遮罩。session 有 15 秒逾時，資料 API 有 20 秒逾時。
- 股票總覽／趨勢／ETF 明細／法人各自完成、各自顯示與報錯，慢速或失敗明細不清掉已成功內容。每次請求都有取消與身分／請求世代防護。
- 海外報表不再等待可用清單和歷史日期；三個 API 同時開始，報表完成立即顯示，所選日期使用該回應的實際 reportDate。單檔台灣 ETF 的初次讀取仍先確定有效資料日，避免猜日期；該階段也顯示載入狀態。
- 今日情報／市場／海外路由在可用時先呈現 HTML 中既有的匿名建置摘要。只擷取 escaped 公開 HTML 的文字，明確標示建置快照與原資料日期，最新回應完成即移除，不以快照冒充即時資料。缺快照不阻擋其他內容；不從會員回應建立跨重載快取。建置抓取最長等待 10 秒，失敗可略過。

## 快取策略

瀏覽器記憶體最多 64 筆，同一分頁 30 秒內直接重用成功結果；30 秒後重新驗證，最多 5 分鐘的舊資料可先顯示。既有股票／訊號／風格／比較的快取先顯示流程保留，績效與市場等也可先使用已取得資料。手動重新整理先清除記憶體快取，確實重新請求；登入／登出同樣失效。失效前發出的回應不能重新填入新世代快取。資料不寫 localStorage 或 sessionStorage。

伺服器已有資料同步後的 generation 失效機制與 TTL；本次沒有清除正式 Redis／Mongo 快取，也沒有改索引、TTL、排程或雲端服務。既有每五分鐘 app-version 檢查是程式版本更新機制，與研究資料快取不同。定時清空整個快取會讓更多請求回到慢查詢，這次採明確期限、手動更新、身分失效與既有同步失效。

2026-10-17 正式站匿名單次抽樣：market/bootstrap 約 6.15 秒、global daily-report 約 2.18 秒、MU overview 約 1.43 秒、MU history 約 1.50 秒。這是尚未部署本次修改的有界樣本，不能當作 p95／冷啟動或本次改善後的正式速度。首批資料改善由本地受控延遲驗證；後端長期延遲仍需部署後另外量測。
